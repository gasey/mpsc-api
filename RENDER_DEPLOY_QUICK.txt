🚀 RENDER DEPLOYMENT CHECKLIST

1. Create Postgres Database:
   → Go to https://render.com/dashboard
   → Click "New +" → "PostgreSQL"
   → Name: mpsc-db
   → Create Database
   → COPY the "External Database URL" (DATABASE_URL)

2. Create Web Service:
   → Click "New +" → "Web Service"
   → Connect GitHub repo: https://github.com/gasey/mpsc-api
   → Name: mpsc-api
   → Environment: Python 3.11
   → Build Command: pip install -r requirements.txt && python manage.py migrate
   → Start Command: gunicorn mpsc_api.wsgi
   → Click "Create Web Service"

3. Add Environment Variables:
   In Render dashboard → mpsc-api → Environment
   
   SECRET_KEY=your-super-secret-key-here-change-this
   DEBUG=False
   ALLOWED_HOSTS=mpsc-api.onrender.com
   DB_NAME=mpsc_db
   DB_USER=postgres
   DB_PASSWORD=<copy from postgres service>
   DB_HOST=<copy from postgres service - use .internal URL>
   DB_PORT=5432
   CORS_ALLOWED_ORIGINS=http://localhost:5176,http://localhost:3000

4. Deploy & Test:
   Your API will auto-deploy after push to main
   Test: curl https://mpsc-api.onrender.com/api/questions/stats/

5. Load Questions (SSH into Render):
   python manage.py load_questions /path/to/mpsc_bank_converted.json
   
   OR upload JSON to Render and load it

That's it! Free backend with Postgres database 🎉
